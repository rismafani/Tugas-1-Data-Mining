# Tugas 1 Data Mining

Repository ini berisi dokumentasi dan hasil pengerjaan Tugas 1 mata kuliah Data Mining, yaitu proses preprocessing data menggunakan Python melalui Google Colab.

## Identitas
- **Nama:** Risma Fani Dwi Natasya
- **Program Studi:** Sistem Informasi
- **Mata Kuliah:** Data Mining

## Deskripsi Tugas
Tugas ini bertujuan untuk melakukan preprocessing pada dataset pelanggan agar data menjadi lebih bersih dan siap digunakan untuk proses analisis data.

## Dataset
Dataset yang digunakan berisi data pelanggan dengan informasi usia, jenis kelamin, kota, pendapatan bulanan, frekuensi belanja, total belanja, metode pembayaran, kategori favorit, rating kepuasan, tanggal daftar, dan status churn.

## Tahapan Preprocessing
1. Memuat dan memahami dataset.
2. Mengidentifikasi missing values.
3. Menyeragamkan data kategorik.
4. Mengidentifikasi nilai tidak valid.
5. Mendeteksi dan menangani outlier menggunakan metode IQR.
6. Mengisi missing values menggunakan median dan modus.
7. Mengidentifikasi dan menghapus data duplikat.
8. Mengubah format tanggal menjadi datetime.
9. Memeriksa hasil akhir preprocessing.

## Hasil
Setelah preprocessing, dataset memiliki 160 baris dan 12 kolom, tanpa missing values dan tanpa duplikasi ID pelanggan.
